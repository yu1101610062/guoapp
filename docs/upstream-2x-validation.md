## 合并适配

- 播放器保留稳定分集 ID、会话 ID、续播冲突选择、5 秒本地保存和原网络同步调度。
- 上游 `quiet` 进度写入合并进事务保存入口；远端合并不生成新本地操作。
- 新版画面比例和弹幕样式使用最新本地持久化偏好按字段修改，避免当前播放会话把远端同步的偏好覆盖回去。
- 「删除全部数据」先使同步请求失效，删除后阻止新写入，不删除云端资料；失败时恢复本地访问。
- 保留平板/窗口软键盘弹出时的表单布局修复；同步测试模式缓存独立，跳过正式 Windows 数据迁移。
- 旧 `--all-sources` 命令仍接受，但 2.x 不再使用 `buildAllSources` 链接参数或编译时站源列表。
