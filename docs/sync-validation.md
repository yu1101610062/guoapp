## 站源可用性边界

- 红果：实际播放成功。
- 韩小圈：当前目录请求超时。
- 鬼片：“碟仙怪谈”可加载目录、详情和收藏，但播放列表服务器返回 HTTP 403。
- 青空：“凡人修仙传 第五季”和“野生的大魔王出现了！第二季”可加载目录/详情，播放接口均未提供地址。

因此第二站源的完整实播续播验收未通过；用户确认没有可提供的其他可用剧目，同意按实测结果标注限制。目录和收藏可用不能代替播放验收。上述结果是本次网络和时间下的观察，不代表所有影片或后续时刻均不可用。

## 数据保全记录

初次启动 Windows 测试版时，测试目录尚未隔离旧版 SharedPreferences，触发上游迁移逻辑读取并移除了部分旧偏好键。随后已停止该测试实例，从完整迁移文件恢复原用户、追剧、历史和偏好，并读回核对原有核心记录。恢复材料保存在原应用支持目录下 `sync-isolation-recovery-20261102/`，没有进入源码或交付包。后续已同时隔离 Flutter 偏好前缀、业务数据和 Go 核心目录，并复查原记录仍保留。

项目内早期测试产生的 `memory/`、`memory.device.json`、`linux/` 未纳入构建暂存或交付包，保留待清理。

## 已知限制

- Android 无常驻服务；被系统结束时不保证立即上传，下次启动补传。
- 请求预算为每客户端每账号 100 次/30 分钟，其中自动最多 80 次。首次连接和密集测试消耗较快，达到额度后需等待；不能把这时的延迟算作正常网络下十秒目标通过。
- 应用使用 HTTPS 与系统安全存储，没有增加同步数据端到端加密。
- 模拟故障的自动化测试不能替代实际断电、长期离线多月或所有 Android 厂商后台策略验证。

## 1.0.4：软键盘布局修复
