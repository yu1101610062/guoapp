# 真果鉴：坚果云同步 v1

## 使用

首批目标为 Windows 和 Android 手机/平板，必须同时构建 Flutter 和 Go 的全站源版本。正式版本为 `1.0.3+104`；不传 `--sync-test` 时，Android 应用 ID 保持 `com.duanju.duanju_app`，名称为“真果鉴”，使用原数据目录、偏好前缀和原生核心配置。

此前的独立测试版为 `1.0.3-sync.1+103`：Android 应用 ID 是 `com.duanju.duanju_app.syncdev`，名称为“真果鉴（同步测试）”；Windows 测试数据位于 `sync-test-v1/`，偏好、原生核心和下载目录也独立。测试版的云端绑定不会自动复制到正式版，正式版需为相应本地用户连接云端资料并确认合并。

1. 在坚果云网页的“账户信息 → 安全选项”中，为每台设备创建一个应用密码。
2. 打开真果鉴“设置 → 坚果云同步”，填写邮箱账号、应用密码和设备名称。服务器固定为 `https://dav.jianguoyun.com/dav/`。
3. 点“测试连接并读取资料”。应用会在自己的 `ZhenguojianSync/v1/tests/` 中上传随机测试文件、读回校验、删除。
4. 第一台设备创建云端资料，建议实测用名称“同步验收 20261102”。下一台设备选择同一份资料，名称后的短 ID 帮助区分重名资料。
5. 点“预览合并”，检查追剧和历史数量后确认。每个本地用户单独绑定；设备名称不决定资料身份。
6. 两端都显示最近成功时间后开始观看。暂停、切集、退出播放会尽快上传，另一端点“立即同步”后续播。

不要在聊天、截图或日志里提供应用密码。密码保存在系统安全存储，不写入普通偏好、同步 JSON、恢复副本或应用备份。Android 已禁用系统应用数据备份。数据使用 HTTPS 传输，云端文件没有额外的端到端加密密码。

“断开连接”保留本地和云端资料。“恢复本机合并前副本”仅恢复当前本地用户的追剧、历史和播放偏好，随后暂停自动同步，重新连接并预览才能继续。原有整机应用备份的恢复同样暂停已有绑定。恢复到另一安装实例不会复制设备 ID 或云端凭据。

## 同步范围

| 数据 | 行为 |
| --- | --- |
| 追剧 | 添加和取消同步；保留取消标记 |
| 历史 | 剧集、分集稳定 ID（可用时）、显式集号、位置、时长、观看时间 |
| 播放偏好 | 倍速、清晰度、自动连播、弹幕，按字段合并 |
| 多站源 | 主键包含 `source` 和 `sourceId`；同名或同数字 ID 不跨站合并 |
| 本地限制 | 关闭的站源、未知站源和无权限站源记录保留，但继续受本地可见性限制 |
| 不同步 | 视频、下载任务、搜索、主题、设备设置、站源开关/凭据、本地权限/PIN |

当前播放不会跳到远端进度；远端播放偏好在下一次打开视频时使用。更改当前倍速只产生倍速操作，不把旧会话中的清晰度等值重新覆盖回云端。

历史页无搜索/站源筛选时显示“清空全部”，确认后清空当前用户所有站源及未显示的旧历史，并发布全局清空标记。存在筛选时显示“清空当前”，只删除当前结果。追剧列表不受历史清空影响。

## 协议与持久化

实现入口：`lib/sync/sync_controller.dart`、`sync_transport.dart`、`sync_state.dart`、`sync_merger.dart`。

```text
ZhenguojianSync/v1/
  tests/<random>.bin                       # 连接测试后删除
  profiles/<random-profile-id>/
    profile.json                          # 创建后不覆盖的资料名称/ID
    heads/<device>_<seq>_<sha256>.json.gz   # 每个设备的不可变发布清单
    devices/<device>/
      favorites/<device>_<seq>_<sha256>.json.gz
      history/<device>_<seq>_<sha256>.json.gz
      preferences/<device>_<seq>_<sha256>.json.gz
```

每个类别文件含 `protocol=1`、`recordVersion=1`、记录和删除标记。一个设备先写入变化的类别，逐个 GET 读回核对摘要，再发布并读回清单，最后确认本地上传版本。上传响应丢失时先 GET 检查。序号在上传前持久化，重传不会刷新记录时间。没有共享覆盖文件、WebDAV 锁或跨设备原子操作依赖。

拉取时先列出 `heads`，按设备取最大序号。未变化的清单/类别不重复下载。所有新类别通过版本、身份、字段、摘要和解压大小检查后一次性合并；任何损坏、未知版本或不完整目录使整批拒绝。网络字节和解压后的 JSON 均限制为 16 MiB，单快照最多 100000 个记录，目录达到 750 项时拒绝当作完整列表使用。

清理只处理本设备文件：保留最近三个经过校验的清单、每类最近三个版本，以及这些清单引用的其他版本。手动同步或每五次发布尝试清理；清理使用自动请求额度，预算不足/断网时延期，不占手动保留额度。删除标记不按离线天数过期。

安装标识位于 store 目录之外，不进入普通备份。实际写入设备 ID 由安装标识和本地用户 ID 派生，避免同一安装的两个本地用户互相覆盖云端版本。

本地每个用户的 `sync.json` 保存合并状态、HLC、类别修改计数、已确认计数、已读清单和绑定信息。`LocalFiles.transaction` 先持久化 `transaction.json`，再写业务文件和同步状态，最后删除日志；启动重放未完成事务。已经提交日志但中途写入失败时，需要重启恢复，避免继续写入不一致的内存状态。远端应用不会制造本地操作。元资料刷新也不会改变追剧或观看操作版本。

## 冲突规则

- HLC 由物理时间、逻辑计数和设备 ID 组成；每个操作保留原始时间。收到远端版本后观察时钟；通过 HTTPS 响应的 `Date` 估算偏差，大于五分钟标记不可靠。
- 追剧每个键取最新操作，包括取消标记；首次绑定将本地追剧视为导入记录，尊重云端取消。
- 历史每部剧保留删除标记和最多三个设备/会话的位置；清空操作有独立全局屏障。展示层的 300 条裁剪不生成删除操作。
- 播放位置按 HLC 取最近有效记录，不按最大进度取值，因此主动重看能够从较早位置开始。多个接近时间或有时钟异常的候选在续播时让用户选择。
- 分集先匹配唯一稳定 ID，再匹配唯一显式集号；无法确定时提示手动选集，保留原记录。列表下标不用于跨设备恢复。
- 播放偏好按四个独立字段合并，首次合并重叠字段以云端为准。

## 调度和故障

本地仍每 5 秒保存进度。连续播放每 60 秒最多安排一次进度上传；暂停、切集和退出通常一秒后触发。追剧、删除及偏好在最后一次连续修改后五秒触发。前台每 120 秒检查发布清单。启动、前台恢复、切换用户先拉取再上传。

续播时，距离上次拉取超过 30 秒会等待最多三秒，超时显示“云端进度待同步”并使用本地位置。同一用户只执行一个同步任务；切换用户使旧请求失效并关闭传输连接。Android 没有新增常驻服务，后台上传是尽力而为，被系统结束后下次补传。

同一客户端按账号持久化 30 分钟请求预算：自动请求最多 80 次，另留 20 次供手动操作，总计 100 次。服务器 `Retry-After` 也按账号保存，重启或切换用户不能绕过等待。大量首次导入、反复连接测试或大量设备变更可能耗尽手动预算，等待窗口恢复后继续。认证错误停止自动重试，更新应用密码后再连接；其他错误保留待上传状态并退避。同步日志只记阶段、错误类别和待上传数量。

坚果云官方公布的免费账户限制是 600 次/30 分钟，由全部设备及其他 WebDAV 应用共用；客户端的预算更保守。[官方限制说明](https://help.jianguoyun.com/?p=2064)

## 构建与复验

正常全站源构建：

```powershell
python scripts/build_windows.py --all-sources
python scripts/build_android.py --all-sources
```

双端验收使用独立测试模式：

```powershell
$env:JAVA_HOME = 'C:\Program Files\Java\jdk-21'
$env:Path = "C:\Ruby33-x64\msys64\ucrt64\bin;$env:JAVA_HOME\bin;$env:Path"
python scripts/build_windows.py --all-sources --sync-test
python scripts/build_android.py --all-sources --sync-test
flutter test --no-pub --dart-define=ALL_SOURCES=true
dart analyze lib test
# 在 native 目录执行：
go test -ldflags='-X duanjuapp/native/core.buildAllSources=true' ./...
```

环境：Flutter 3.44.1 / Dart 3.12.1、JDK 21、Android NDK 28.2.13676358、Visual Studio 2026、MinGW GCC 15.2。当前 Flutter SDK 对锁文件中的部分更新依赖进行了兼容解析，已更新并保留 `pubspec.lock`。Windows 构建工具在中文路径下出现 `app.dill` 路径编码错误，因此本次用英文暂存目录构建，再把产物交回项目目录。插件目录使用本地 NTFS junction，无需修改 Windows 开发者模式。

测试 APK 使用本机 debug 签名。正式 Android 构建使用维护者自己的固定签名密钥；构建脚本支持 `ANDROID_KEYSTORE_PATH`、`ANDROID_KEYSTORE_PASSWORD`、`ANDROID_KEY_ALIAS`、`ANDROID_KEY_PASSWORD` 环境变量，或本地 `android/key.properties`。密钥和密码不提交 Git。后续升级必须继续使用同一签名。

上游发行版的签名不同，无法直接覆盖安装本分支。更换前必须先备份；普通设备使用应用的导出/恢复功能，已下载视频另行保存。仅保持包名不能防止卸载删除数据。本次已授权的 Root 实机迁移另做完整私有目录备份、文件摘要核验、卸载安装、恢复权限和 SELinux 标签，再验证旧记录迁移；这一过程不代表普通非 Root 设备可自动保留全部数据。详见 [Android 更新规则](https://developer.android.com/google/play/app-updates)。

macOS/iOS/Android TV 的包构建和安全存储集成未列入本次验收。

验收的实测结果、限制和包摘要见 `sync-validation.md`。
